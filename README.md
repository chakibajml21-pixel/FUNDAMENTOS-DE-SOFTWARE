# 💳 Quantum Core

## Patrón de Diseño Singleton

### Descripción

Este proyecto implementa el **Patrón de Diseño Singleton** en Python para simular el funcionamiento de una Fintech.

El sistema cuenta con una clase llamada **GestorBanco**, encargada de administrar los clientes, las cuentas y las transacciones. Gracias al patrón Singleton, solo existe una única instancia de esta clase durante toda la ejecución del programa.

Además, el proyecto incluye las clases **Usuario**, **UsuarioEmpresa** y **Wallet**, aplicando conceptos de Programación Orientada a Objetos como herencia, composición y encapsulamiento.

---

## Objetivo

Aplicar el patrón Singleton para garantizar que el sistema tenga un único gestor encargado de controlar la información del banco.
